proofpilot beta
===============

proofpilot is a macOS selected-text correction shortcut.

Install
-------

1. Open proofpilot-1.5.22.2.pkg.
2. Finish the installer.
3. Open proofpilot from Applications for setup.
4. Enable local AI if you want Ollama-backed correction.

Ollama
------

proofpilot does not bundle Ollama model files. If Ollama is not installed, setup opens the official Ollama download page. If Ollama is installed, setup lists the models already available on this Mac and lets you choose one.

Use
---

1. Select text in an app like Notes, TextEdit, Mail, or a browser.
2. Press Command-Shift-K.
3. proofpilot replaces the selected text with the corrected version.

Signing note
------------

The proofpilot app inside this package is Developer ID signed. The package wrapper is not Installer-signed from this build session.

Uninstall
---------

Open proofpilot from Applications and click remove.
