Use the model already on your Mac.

proofpilot can use Ollama for stronger sentence repair and formal rewrites. During setup, it checks whether Ollama is installed, lists the models already loaded on your Mac, and lets you choose which one to use.

If Ollama is missing, proofpilot opens the official Ollama download page. It does not include Ollama model files, because model licenses belong to those models.
